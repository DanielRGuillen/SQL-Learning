# Chapter 01 - Analysis with SQL

## Overview

This chapter introduces SQL techniques for data analysis.

The objective is to understand how SQL can be used to
explore, transform, and analyze data to generate insights.

## Learning objectives

- Understand SQL queries for data analysis.
- Explore datasets using SELECT statements.
- Filter records using WHERE.
- Aggregate data using GROUP BY.
- Apply aggregate functions such as COUNT, SUM, AVG, MIN and MAX.
- Sort and organize query results.
